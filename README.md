# 25 Films. 31 Days.

Sinjini vs Sankalp's December 2026 movie-watching challenge.

- **Tracker:** a live scoreboard, weekly checks, fines and the film log
- **Rulebook:** the full rules
- **Pamphlet:** a one-page summary, downloadable as a PDF or an image

The films are stored as GitHub Issues in this repo. The site reads them and works out all the scores. Only issues opened by the two usernames in `config.js` count.

## How to play

| To do this | Use this button on the site | What happens |
| --- | --- | --- |
| Log a film | **+ Log a film** | Fill in the GitHub form and submit |
| Claim a side quest, Sick Day Pass or Double or Nothing | **Claim a bonus** | Fill in the form and submit |
| Record a spot-check on your opponent | **Report a spot-check** | Give their film's issue number (shown in the log) and the result |
| Remove a film you logged by mistake | Open its issue → **Close issue** | Only open issues count |

Then press **Refresh** on the site.

## Settings

Edit `config.js` to change the repo name or either player's GitHub username.
